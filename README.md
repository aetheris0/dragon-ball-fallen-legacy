# Dragon Ball: Fallen Legacy

A static multi-page fan-made website.

## Pages
- `index.html` — home page
- `story.html` — story archive
- `characters.html` — character directory
- `fallen-legacy-goku.html` — full Fallen Legacy Goku profile

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `dragon-ball-fallen-legacy`).
2. Upload every file and the `assets` folder, keeping the folder structure unchanged.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

The character artwork is stored locally at `assets/fallen-legacy-goku.png`, so it will load from the repository without an external image host.
